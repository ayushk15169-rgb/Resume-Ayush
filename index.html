Troubleshooting Guides

Roz ke IT support problems ke chhote, kaam ke fixes.

Printer offline dikha raha hai: fix
  1. Printer ON hai aur network/USB cable theek jud hai, ye check karo.
  2. Settings → Printers & scanners → printer → Open print queue. Printer menu mein Use Printer Offline tick ho to hata do.
  3. Print Spooler restart karo: services.msc → Print Spooler → Restart.
  4. Atki hui jobs clear karo: Spooler stop karke C:\Windows\System32\spool\PRINTERS ki files delete karo, phir Spooler start karo.
  5. Network printer ho to port ka IP sahi hai ya nahi dekho (ping <printer-ip>).
  6. Phir bhi na chale to driver hata kar dubara install karo.
Domain join error: "The specified domain either does not exist or could not be contacted"
  1. PC ka DNS domain controller (ya internal DNS) par point hona chahiye, public DNS par nahi.
  2. ping yourdomain.local aur nslookup yourdomain.local se domain resolve ho raha hai ya nahi dekho.
  3. PC aur server ka date/time sync check karo.
  4. Firewall ya VPN beech mein domain controller ke ports block to nahi kar raha, ye dekho.
  5. Naam ki spelling aur domain admin credentials dubara check karo, phir join karo.
Computer slow chal raha hai: quick checklist
  1. Task Manager mein CPU/RAM/Disk dekho, kaun sa process zyada le raha hai.
  2. Startup apps kam karo (Task Manager → Startup).
  3. C: drive mein kam se kam 15-20% jagah khali rakho.
  4. Windows Update aur driver updates chalao.
  5. Antivirus se full scan karo.
  6. Admin Command Prompt mein sfc /scannow, phir DISM /Online /Cleanup-Image /RestoreHealth.
  7. HDD ho to SSD upgrade sabse bada farak deta hai.
Outlook connect nahi ho raha
  1. Internet check karo aur Work Offline band hai ya nahi dekho.
  2. Safe mode mein kholo: outlook.exe /safe. Chal jaye to koi add-in problem hai.
  3. Control Panel → Mail → Show Profiles se naya profile banao.
  4. Password/MFA expire to nahi hua, ye confirm karo.
  5. Office ko Quick Repair chalao (Settings → Apps → Microsoft 365 → Modify).
